# Geo-Address Formatter

Базова графічна утиліта для збору та локального збереження адресних даних. Проєкт розроблено в рамках індивідуального завдання з навчальної практики (ТОВ «МагнетікВан Муніципальні Технології»).

## Технологічний стек
* Python 3
* PyQt6
* QML (QtQuick)

## Інструкція із запуску
1. Переконайтеся, що на комп'ютері встановлено Python 3.
2. Встановіть необхідну бібліотеку через термінал: `pip install PyQt6`
3. Запустіть головний файл програми: `python main.py`

Введені дані автоматично зберігаються у файл `saved_addresses.txt` у тій самій директорії.
